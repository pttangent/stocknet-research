Interactive Research Report · June 2026

Non-Preset Dynamic Theme Discovery
from Intraday Correlation Networks

A computational study of sector emergence, consensus clustering, and temporal graph neural networks on 5m/15m/30m U.S. equity bars.

Abstract

We construct a multi-frequency market network from 5-minute, 15-minute, and 30-minute intraday returns and detect emerging equity communities without preset sector labels. A bootstrap consensus procedure with GPU-accelerated correlation and Leiden community detection identifies stable co-moving groups. A temporal graph neural network predicts edge persistence and community survival. All experiments are validated against time-shuffle and label-shuffle null models.

3. Bootstrap Consensus

Single-run community detection is noisy. We run 50 bootstrap perturbations (bar subsampling, symbol subsampling, weight noise, resolution jitter) and aggregate a co-membership probability matrix. Only communities that survive the bootstrap are reported.

Figure 3. Left: co-membership probability matrix from bootstrap consensus. Right: mean confidence per detected community.

4. Multi-Resolution Validation

We compare community partitions across 5m, 15m, and 30m using Normalized Mutual Information (NMI). Persistent communities appear in both the high-sensitivity 5m layer and the de-noised 30m layer.
